# Notaker 0.5.0

- Aceleración local con GPU mediante Vulkan, activada por defecto. Conserva Turbo, Spanglish y los ajustes de reconocimiento de 0.4.
- Nueva casilla Acelerar con GPU compatible. Puedes desactivarla para volver a CPU; no requiere reiniciar la app.
- Historial con tiempos separados de Voz e IA para identificar dónde tarda cada dictado. Voz incluye la carga del modelo, pero no el pegado.
- Conserva modelos descargados, clave de DeepSeek, vocabulario, historial y atajos. No añade llamadas de API ni necesita CUDA.

Medición en Ryzen 7 9800X3D / RTX 3050 8 GB con Turbo Q8 y la misma muestra sintética bilingüe: CPU 22,0–22,4 s; GPU 7,6 s en el primer uso y 1,3 s en los siguientes. Mismo texto reconocido; medición sin DeepSeek. El rendimiento y la precisión dependen del audio, hardware y controladores.

Actualiza desde Buscar actualizaciones. Mantén Large v3 Turbo y Español + English · Spanglish. La primera inicialización puede tardar más; los dictados siguientes reutilizan el modelo. El runtime CPU sigue incluido para equipos sin aceleración compatible.
