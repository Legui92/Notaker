# Notaker 0.7.0

- Nueva vista Estadísticas encima de Buscar actualizaciones, con el tema oscuro morado/azul.
- Palabras dictadas, dictados completados, tiempo grabado y promedio ponderado de palabras por minuto.
- Palabras editadas por IA, dictados retocados, correcciones manuales y palabras editadas manualmente.
- Términos aprendidos al corregir, añadidos manualmente y tamaño actual del diccionario. Se corrige el recuento de aprendizaje cuando el diccionario ya tiene 100 términos.
- Contadores locales independientes del historial: no se pierden al borrar dictados ni al superar el límite de 200. Se puede pausar el registro y reiniciar solo las estadísticas.
- Sin llamadas adicionales de IA ni envío de estadísticas. El archivo contiene totales, no textos, audio ni términos del diccionario.

Al actualizar se importa una sola vez el uso recuperable del historial disponible (hasta 200 dictados). Las correcciones se contabilizan desde esta versión: no se inventan cifras anteriores. Una inserción, eliminación o sustitución cuenta como una edición de palabra; la puntuación y las mayúsculas no suman palabras editadas. No es una medida de precisión y no permite atribuir automáticamente correcciones al diccionario.

Actualiza desde Notaker y abre Estadísticas. Se conservan tus modelos, claves y preferencias.
