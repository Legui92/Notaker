# Notaker 0.6.0

- Actualizaciones públicas y anónimas desde GitHub: sin cuenta, GitHub CLI ni access token.
- Eliminado el formulario de acceso y toda lectura de credenciales de GitHub.
- Retirada automática del antiguo token de los ajustes, conservando la clave de DeepSeek, modelos, vocabulario, historial y atajos.
- Se conservan las comprobaciones de origen HTTPS, tamaño, SHA-256, versión y recuperación si la nueva versión no arranca.
- Mensajes claros ante límites temporales de GitHub, sin pedir credenciales.

Usa Buscar actualizaciones → Actualizar y reiniciar. Si una versión antigua falla al reutilizar un token caducado, cierra Notaker desde la bandeja y abre este EXE una vez; no necesitas volver a configurar la IA ni descargar el modelo.
