# Notaker 0.3.0

- Tema oscuro por defecto, con superficies azul noche y acentos morados y azules.
- Actualizaciones desde la aplicación: descargar, verificar SHA-256, sustituir el ejecutable y reiniciar.
- Recuperación de la versión anterior si la nueva no confirma su inicio.
- Acceso a releases privadas mediante GitHub CLI o token protegido con Windows.
- Se conservan modelos, claves, vocabulario, historial y atajos al actualizar.

Esta es la primera versión con actualizador. Para pasar desde 0.1/0.2, cierra Notaker desde la bandeja y abre este Notaker.exe una vez. Las versiones posteriores se instalan desde Buscar actualizaciones → Actualizar y reiniciar.
