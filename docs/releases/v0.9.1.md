# Notaker 0.9.1

- Corrige una espera indefinida en Puliendo escritura cuando la IA entrega las cabeceras pero no termina la respuesta.
- El limite de 45 segundos cubre toda la respuesta. Si vence, se entrega la transcripcion original y se liberan los controles.
