# Notaker 0.9.0 — Recuperación de dictados

- Guarda fragmentos de audio cifrados para tu usuario de Windows mientras dictas. Si ocurre un fallo o se cierra el proceso, permite recuperar los fragmentos completos al reabrir.
- Nuevo botón **Recuperar dictados** para reintentar con el modelo seleccionado, exportar un WAV o eliminar una copia. El WAV exportado queda sin cifrar en la carpeta que elijas.
- Conserva el texto reconocido antes de la limpieza con IA. Las copias se eliminan cuando el resultado se copia al portapapeles o se guarda correctamente en el historial. Los pendientes se conservan hasta recuperarlos o eliminarlos.
- Comprueba la carga nativa del modelo antes de abrir el micrófono. El indicador muestra «Preparando · aún no graba» hasta que empieza la escucha. Si la inicialización GPU falla con una excepción recuperable, intenta CPU.
- Protege las dependencias extraídas del ejecutable frente al borrado por limpieza temporal mientras está abierto.
- Contiene excepciones de la bandeja y evita abrir el diálogo genérico de error de WinForms desde ese callback.
- Añade diagnósticos locales con versión, etapa, tipo de excepción y traza de métodos. No registra audio, transcripciones, vocabulario, claves ni mensajes de excepción.

Las grabaciones perdidas en versiones anteriores no se pueden reconstruir con esta actualización. Los nuevos respaldos empiezan a guardarse al actualizar.
