# Notaker 0.4.0

- Modelos locales Large v3 Turbo (8 bits, 834 MiB) y Large v3 completo (2,9 GiB), además de Base y Small.
- Modo Español + English / Spanglish con contexto bilingüe y decodificación por búsqueda de haces. No solicita traducción.
- Edición con IA más conservadora: conserva los términos en cada idioma y evita adivinar palabras ambiguas. Una sola llamada al modelo configurado, sin razonamiento adicional.
- Limpieza local de caracteres Braille e invisibles espurios, conservando tildes, saltos de línea y símbolos reales.
- Las actualizaciones conservan la clave de API, ajustes, vocabulario e historial. Selecciona manualmente Turbo o Large v3 y descarga el modelo para empezar a usarlo.

El audio sigue procesándose localmente. Los modelos grandes no añaden coste de API; sí requieren más memoria y pueden tardar en CPU. Ningún modelo garantiza un dictado perfecto ni recuperar palabras mal reconocidas a partir del texto solamente.

Descarga Notaker.exe o usa Buscar actualizaciones en Notaker 0.3+. No se necesita extraer el ZIP para actualizar. El repositorio es privado: inicia sesión en GitHub o configura el token en el actualizador.
