# Notaker 0.10.3

- Indicador de dictado compacto: 44 px de alto, con nivel de voz, punto y timer durante la escucha.
- Botón × para cancelar durante la preparación, grabación, transcripción o limpieza con IA. Al descartar no se copia ni pega texto ni se añade el dictado al historial.
- Estado «Cancelando» mientras termina el trabajo activo. El motor se detiene antes de permitir otro dictado. Si falla la eliminación del respaldo, se informa y sigue disponible en Recuperar dictados.
- La preparación aclara que el micrófono aún no está grabando. El indicador conserva el foco del editor de destino.

Probado con micrófono real, clic físico, cancelación de preparación nativa, fallo de parada simulado y limpieza con IA simulada. No se hicieron llamadas de pago. Se conservan modelos, clave de API, preferencias y transcripción durante la grabación.

Actualiza desde **Buscar actualizaciones**.
