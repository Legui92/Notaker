# Notaker 0.8.0

- Nueva N de cinta plegada en morado y azul, elegida entre tres propuestas. El mismo icono identifica el ejecutable, la barra de título, la esquina superior izquierda y la bandeja del sistema.
- Nuevo ajuste **Iniciar Notaker con Windows**. Registra el ejecutable actual para abrirlo al iniciar sesión y aparece en las aplicaciones de arranque del Administrador de tareas.
- Si se deshabilita desde Windows, Notaker respeta esa decisión y ofrece abrir la configuración de inicio para habilitarlo de nuevo.
- Conserva modelos, clave de IA, historial, vocabulario y estadísticas. No requiere reinstalar ni configurar un token de GitHub.

Guarda Notaker.exe en una carpeta que vayas a conservar antes de activar el inicio. Si mueves el archivo, desmarca y vuelve a marcar la opción desde su nueva ubicación. Actualizar dentro de Notaker conserva la ruta y el registro de inicio.
